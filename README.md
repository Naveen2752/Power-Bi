# Power BI Dashboard Analysis - HR & Customer Insights

This repository features interactive dashboards created using **Power BI** to visualize and analyze HR data, customer demographics, and key performance indicators (KPIs). The dashboards are designed for clarity, interactivity, and actionable insights.

## 📌 Features

- HR Dashboard:
  - Visualizes gender distribution and other HR KPIs
  - Highlights HR metrics for better workforce planning
- Customer Dashboard:
  - Demographic breakdowns (age, location, etc.)
  - Customer behavior and segmentation insights
- KPI Dashboard:
  - Key metrics represented using cards and visuals
  - Easily track performance at a glance
- Clean layout with slicers, filters, and responsive visuals

## 🛠️ Tools Used

- Power BI Desktop
- Data Transformation using Power Query
- DAX (Data Analysis Expressions)
- Card, Bar, Pie, and Line Charts
- Slicers and Drill-Down Features

## 🚀 How to Use

1. Open the `.pbix` file using Power BI Desktop.
2. Explore the report pages using slicers and visual filters.
3. Hover over visuals for tooltips and deeper insights.
4. Connect your own dataset to reuse the visual templates.

## 💼 Use Case

These dashboards help HR teams understand gender dynamics and KPIs, while giving business stakeholders a snapshot of customer segments and behaviors to support decision-making.
